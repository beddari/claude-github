roblox-gdd

A starting point for making a Roblox game with Claude, in the Code tab of Claude Desktop. The code is Luau that Rojo syncs into Studio. The design is an Obsidian vault shown as a page tree. Claude reaches Studio and Obsidian through their MCP servers. Four skills keep the design and the code in agreement, and four prompts take you from an empty folder to the first system.

Why

A game design document drifts from the code within weeks. Claude can keep the two together, but only if it knows where each lives, how each may change, and how to check that they agree. Rojo overwrites edits made in Studio. PageTree keeps a page's children in a folder next to it, so a rename must move both. A remote has to match in the code, the network page and the canvas. The kit writes these rules down once, as skills, and adds a script that finds drift.

What you get

What it finds

check-gdd.sh on a copy of the template with six planted problems. CI plants these and more, with Windows line endings, on every run: 

$ bash .claude/skills/gdd-code-sync/scripts/check-gdd.sh
!!! Remote BuyItem is in Remotes.luau but has no '### BuyItem' in Networking.md
!!! design/Game/Systems/Combat System/ holds pages but design/Game/Systems/Combat System.md is missing
!!! design/Other/ holds pages but design/Other.md is missing
!!! More than one page is named 'damage'; [[damage]] is ambiguous
!!! design/Game/Systems/X.md lists code: src/server/Services/Nope.luau, which does not exist
!!! design/Game/Systems/X.md lists remote Ghost, which Remotes.luau does not declare
!!! 6 problem(s) between design/ and src/!

Haiku, Sonnet and Opus each added the same Coins system to a copy of the template by following the skills. All three passed this check, the luau-lsp type check, StyLua and a Rojo build.

Plug it in

You need Claude Desktop, Git, Roblox Studio, Obsidian 1.13 or later with the PageTree and Semantic Notes Vault MCP plugins, and Rokit. In the Code tab, start a Local session on an empty folder and paste the first prompt: 

# prompts/1-setup.md, in a Code-tab session on an empty folder
Set up a new Roblox game project in this folder from the roblox-gdd kit.
…

The README has the hand steps between the prompts: opening the vault, the plugin settings, the API key, and Studio's Quick connect.

Use it

# once the connections pass: interview, then the first pages
prompts/3-design-kickoff.md

# once per system: page, code, network contract, checks, playtest
prompts/4-first-feature.md

# any time, in the project: do design/ and src/ agree?
bash .claude/skills/gdd-code-sync/scripts/check-gdd.sh
