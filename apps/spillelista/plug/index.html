spillelista

A guessing game on one of your own Spotify playlists. It shuffles the list and plays one song at a time; you guess the year, then flip the card to see the year, title, artist and album. One HTML page with no server and no build step.

Open the game →

Why

A playlist you know is the best quiz, and Spotify already has it. The page logs in with Spotify in the browser, with OAuth PKCE, so there is nothing to host but static files: GitHub Pages is enough.

What you get

keywhat it does
SpaceFlips the card: year, title, artist and album
Enter, →The next song
PPlay or pause
RThe current song from the start

The page is in Norwegian. Playback goes through the Spotify Web Playback SDK, which needs a Spotify Premium account.

Plug it in

To serve it yourself, register an app in the Spotify dashboard, put its client ID in config.json, and add the address the page is served from as a redirect URI. A client ID is not a secret. 

git clone https://github.com/beddari/claude-github && cd claude-github
# apps/spillelista/config.json: spotify.clients.spillelista.clientId
task spillelista:serve      # http://127.0.0.1:8000/
served byredirect URI
task spillelista:servehttp://127.0.0.1:8000/
task servehttp://127.0.0.1:8000/apps/spillelista/
